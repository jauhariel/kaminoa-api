Cara Pakai

Tiga langkah, kurang dari semenit.

01

Login Google

Klik tombol mulai, login pakai akun Google. Akun API kamu langsung dibuat otomatis.

02

Ambil API Key

Buka /dashboard, salin API key pribadimu. Satu key untuk semua endpoint.

03

Panggil API

Kirim key di header x-api-key setiap request. Cek sisa kuota di dashboard.

terminal
# contoh request
curl "https://api.kamu.com/ai/chatgpt?text=halo" \
  -H "x-api-key: kmn_xxxxxxxxxxxx"

# respons kuota ada di header setiap respons
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 99
